# Raster Graphics Lab — Вариант 1

## 1. Описание проекта

Данный проект представляет собой программу для растровой обработки изображений, разработанную на языке C++ с использованием стандарта C++17.

В рамках проекта реализован вариант 1 задания — создание RGB-градиентов с несколькими цветовыми точками и применение фильтров к изображениям.

Для сохранения изображений используется текстовый формат PPM (P3).

## 2. Цель работы

Цель работы — изучить принципы создания и обработки растровых изображений, реализовать построение цветовых градиентов, освоить работу с пикселями и применить основные методы обработки изображений.

## 3. Функциональные возможности

Программа поддерживает следующие возможности:

### 3.1. Создание RGB-градиентов

- Создание градиента минимум из двух цветовых точек.
- Настройка положения каждой цветовой точки в диапазоне от 0 до 1.
- Интерполяция цветов между соседними точками.
- Поддержка четырёх направлений градиента:
  - Horizontal — горизонтальный;
  - Vertical — вертикальный;
  - Diagonal — диагональный;
  - Radial — радиальный.

### 3.2. Обработка изображений

Реализованы три фильтра:

- **Sepia** — преобразование изображения в оттенки сепии.
- **Invert** — инвертирование RGB-каналов.
- **Contrast** — изменение контрастности изображения с помощью настраиваемого коэффициента.

Также предусмотрено сохранение исходного изображения без применения фильтров.

### 3.3. Экспорт изображений

Результаты работы программы сохраняются в формате PPM (P3).

Файлы записываются в текстовом формате и содержат:
- идентификатор формата P3;
- ширину и высоту изображения;
- максимальное значение цветового канала;
- RGB-значения каждого пикселя.

Длина одной строки с данными не превышает 70 символов.

### Назначение основных компонентов

- **Color** — хранение и обработка цвета, интерполяция, смешивание и преобразование в оттенки серого.
- **Image** — хранение растрового изображения и управление пикселями.
- **Canvas** — контекст рисования, управление цветом, сглаживанием и областью отсечения.
- **Gradient** — построение RGB-градиентов.
- **ImageFilter** — применение фильтров Sepia, Invert и Contrast.
- **IPNMExporter** — абстрактный интерфейс для экспорта изображений.
- **PPMExporter** — сохранение изображений в формате PPM (P3).
- **main.cpp** — основной интерфейс взаимодействия с пользователем.

## 5. Используемые технологии

- Язык программирования: C++17.
- Компилятор: GCC (MinGW).
- Система сборки: CMake.
- Среда разработки: Visual Studio Code.
- Формат выходных изображений: PPM (P3).
- Для реализации проекта используются стандартная библиотека C++ и контейнер `std::vector`.

Внешние графические библиотеки не используются.

## 6. Сборка проекта

Для сборки проекта необходимо установить компилятор C++ с поддержкой C++17 и CMake.

Откройте терминал в корневой папке проекта и выполните:

```powershell
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
```

После успешной сборки исполняемый файл будет находиться в папке `build`.

## 7. Запуск программы

Для запуска основной программы выполните:

```powershell
.\build\RasterGraphicsLab.exe
```

Следуйте инструкциям, отображаемым в консоли программы. Пользователь может задать размеры изображения, количество и параметры цветовых точек, направление градиента и тип обработки изображения.

## 8. Запуск тестов

Для проверки работы градиентов выполните:

```powershell
.\build\GradientTest.exe
```

Для проверки фильтров выполните:

```powershell
.\build\ImageFilterTest.exe
```

Тестовые программы создают изображения для проверки реализованных алгоритмов.

## 9. Результаты работы

Созданные изображения сохраняются в каталоге:

```text
output/ppm/
```

В каталоге находятся результаты построения градиентов, применения фильтров и работы основной программы.

## 10. Обработка ошибок

В программе предусмотрена обработка некорректных входных данных.

В частности, проверяются:
- количество цветовых точек;
- допустимость значений RGB;
- корректность положения цветовых точек;
- размеры создаваемого изображения;
- коэффициент изменения контрастности;
- ошибки открытия и записи выходных файлов.

Для обработки ошибок используются стандартные исключения C++, включая `std::invalid_argument`, `std::out_of_range` и `std::runtime_error`.

## 11. Заключение

В результате выполнения проекта реализована программа для создания RGB-градиентов с несколькими цветовыми точками и обработки растровых изображений.

Реализованы четыре направления градиента, три фильтра обработки изображений и экспорт результатов в формат PPM (P3). Работа основных компонентов проверяется с помощью отдельных тестовых программ.
